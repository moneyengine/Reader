# 轻读 · 原生桌面版

Windows 10/11 x64 独立 WPF 朗读工具。无需浏览器或另装 .NET。

## 启动

双击项目目录的「启动轻读.cmd」，或运行 `release/LightReader-voice-performance-win-x64/LightReader.exe`。请先关闭旧版，避免误用旧窗口。发布目录中的文件需要一起保留。

## 音色展开性能与应用图标（2026-11-12）

- 分类树启用 WPF 虚拟化和容器回收，并限制滚动视口高度，只创建当前可见的音色控件。专用下拉模板移除普通 ComboBox 的隐藏平铺列表，避免重复生成音色控件。
- 保留语言、地区、性别的多级分类，以及搜索、当前音色路径展开、键盘选择和不兼容音色保护。
- 程序文件、主窗口、任务栏及托盘统一使用蓝色书本图标；ICO 包含 16–256 像素的七种尺寸。图标生成脚本为 `tools/Build-AppIcon.ps1`。
- `--check-categories-tray` 增加 1 万音色展开压力测试，检查实际控件数量、末尾音色滚动及选择，并记录首次与重复展开耗时。

## 多级音色分类与系统托盘（2026-11-12）

- 音色下拉框改为可展开的分类树。Edge 按「语言 → 地区/口音 → 男声/女声 → 音色」组织，例如「中文 → 普通话（中国大陆）→ 女声 → 晓晓」。
- Windows 本机按语言与 Windows/SAPI 分组；火山音色按当前接口/其他接口及官方场景分类分组，自定义音色单列，不凭名称猜测性别。
- 点分类只展开/折叠；点具体音色才提交选择。搜索支持名称、ID、语言、地区及分类路径，多关键词以空格分隔；搜索不清空当前音色。支持收起分类、空结果提示及键盘操作。
- 主程序运行时在 Windows 右下角通知区域显示蓝色书本图标；系统可能将它放在「^」折叠区，是否固定显示由 Windows 决定。
- 双击托盘图标显示主窗口，悬浮模式下会展开。右键菜单提供显示主窗口、开始/暂停/继续朗读、停止与退出；菜单与提示随播放状态更新。
- 最小化仍保留托盘入口，关闭主窗或选择退出会正常退出并清理图标；没有改成关闭后隐身后台常驻。
- 验证命令：`dotnet run --project tests -- --check-categories-tray`。覆盖分类保真、筛选保留选择、叶子选择、空结果、收起、托盘菜单/状态/释放和最小化恢复。

## 免费在线自然语音（2026-11-12）

朗读引擎新增「Edge 自然语音」，可选晓晓、云希等中文神经音色；全目录可搜索，中文优先显示。它使用开源 edge-tts 客户端访问微软在线服务，无需 API Key，正文会发送到微软，不是离线开源语音模型。

当前电脑已配置独立 Python 环境并验证 edge-tts 7.3.1，旧 7.2.8 在实际合成时返回 403。新电脑需要 Python 3.10+，并运行 tools/Install-EdgeTts.ps1 安装可选依赖；步骤见 FREE-VOICE-README.md。软件不在启动时自动安装包、不下载大模型，也不改变已有引擎选择。

支持真实文字边界、语速音调、统一暂停/继续/停止，短段合成时最多预取下一段。已用项目测试文本验证真实晓晓合成、MP3 解码、云希原生窗口静音播放、暂停/继续、停止和子进程取消；测试只调用微软服务，未调用火山付费接口。网络服务异常时显示原因，可手动切回 Windows 本机。

## 液态玻璃原生界面

- 按已确认的 v2 设计实现半透明玻璃外壳、胶囊控件、左侧导航、清晰正文和固定播放器；所有按钮、文字和图标是可交互原生控件，未把效果图或 HTML 当作界面嵌入。
- Windows 11 22621 及以上优先使用原生 Desktop Acrylic。关闭系统透明效果、显卡不支持或旧系统时使用不透明材质回退。Windows 材质与 iOS 动态光学折射并非完全一致。
- 右上角「•••」可切换深浅主题、减少透明度、打开字典、API 调试及数据导入导出；「设置」保留服务密钥、模型和识别语言配置。
- 播放/暂停/继续共用一个主按钮。常用语速直接选择；「更多」展开音调、音量、语速滑块、字体和音色刷新。音色搜索框支持名称、语言和 ID。
- 图片识别后在右侧原图对照中缩放或重新识别，可关闭面板腾出正文空间。历史页显示缩略图并将完整文本与原图并排展示。
- 悬浮播放器置顶，展开时恢复原窗口尺寸和最大化状态。标题栏保留 Windows 拖动、缩放、最小化和关闭。
- 增加键盘焦点边框、搜索框提示及空正文引导。低透明度偏好与主题一并加密保存。

本轮验证：原生窗口渲染、真实本机播放及统一暂停/继续、剪贴板图片 OCR、历史原图、模型 ID 编辑框、调试设置窗口、任意语速显示、透明度回退、深色模式、820 DIP 窄窗口、普通/最大化窗口的悬浮恢复和 Windows 标题栏 HTCAPTION 命中检测。桌面锁屏阻止了额外的真实鼠标拖动和点击验收；不把该项视为已通过。未新增云端付费调用。

## 文字与截图历史（2026-11-11 修复）

- 修复历史按钮创建窗口后没有显示的问题。历史窗口左侧选择记录，右侧分别查看完整文字和原始截图。
- 输入、粘贴文本自动保存，不必先朗读；编辑同一篇正文更新该条记录，粘贴新内容、截图或载入图片创建新记录。
- 保存最近 30 条记录。原图在识字前保存，识字失败或停止后也可查看原图并重试。
- 支持搜索、复制完整文本、载入文本及原图、载入并朗读、导出原始图片、重新识字、删除和清空历史。
- 重启后仍可查看图片。旧版加密文字历史首次启动自动迁移；旧版未保存的截图无法补回。
- 原生阅读数据导出 JSON 包含正文、参数、历史和原图，导入时恢复。导出的 JSON 是明文，请自行保管；不包含服务密钥。图片总量超过 96 MB 时提示减少历史后导出。
- 本地文字历史和图片使用 Windows 当前用户 DPAPI 加密。新版状态文件位于 `%LOCALAPPDATA%/LightReader/native-reader-v2.dat`，原图位于同目录 `history-images`。旧状态文件保留。
- 原图按内容去重，单图限 32 MB，图片存储总量限 160 MB；删除记录或超出 30 条时清理不再引用的原图。

## 朗读与识字

- 选择 Windows 本机引擎即可免费离线朗读；下拉框列出本机实际可用的 Windows / SAPI 音色，数量取决于语言组件。支持调节语速、音调、音量、暂停继续、跳转和文字高亮。
- 火山引擎使用音频生成 HTTP API，设置中填写对应语音服务密钥。云端生成需要联网并可能计费，音色须符合所选接口及账户权限。接口配置另见 AUDIO-README.md。
- 「本机 OCR · 免费」使用 Windows 文字识别组件，无需密钥，图片不上传。识别语言在服务设置选择。
- 「粘贴文字/图片」支持截图工具复制的图片，图片优先于同剪贴板的说明文字；编辑区 Ctrl+V 也支持图片识字。
- 可从文件选择图片或框选屏幕。识字后可校对，再点击播放；「查看原图」和历史均能查看实际输入图片。
- 豆包 OCR 是可选云端服务，需要方舟密钥及支持图片输入的模型 ID / 推理接入点 ID，不能填 `apikey-…` 资源 ID。本机识别失败不会自动切换到付费服务。
- 悬浮按钮折叠并置顶；原生标题栏可拖动窗口。字典联网查询需手动启用。

## 开发与验证

发布统一运行 `./tools/Publish.ps1`，固定覆盖 `release/LightReader-win-x64`，不再创建按功能命名的新目录。按用户授权，发布时默认强制结束该固定目录中的轻读进程，再覆盖发布；这会中断朗读，尚未自动保存的编辑可能丢失。发布成功后清理旧目录；其他目录中正在运行的旧版本暂时跳过。

每次完成发布及验证后运行 `./tools/Clean-OldBuilds.ps1`，保留主程序集修改时间最新的完整发布目录，更新启动入口，并清理其余发布版及 `src/tests` 的 `bin/obj` 编译输出。源码和本机阅读数据不受影响。正在运行的旧版跳过，关闭后重跑即可。预览删除范围使用 `./tools/Clean-OldBuilds.ps1 -WhatIf`。该脚本按需运行，不会后台监控或自动终止程序。

需要 .NET 9 SDK。`dotnet build src/LightReader.csproj`。

测试命令：

```
dotnet run --project tests
dotnet run --project tests -- --check-local-ocr
dotnet run --project tests -- --check-native-reader
dotnet run --project tests -- --check-glass-ui
# 以下为显式联网测试，只使用项目自带测试文字
dotnet run --project tests -- --check-edge-live
dotnet run --project tests -- --check-edge-ui
```

先运行本机 OCR 测试生成中英文图片样本，再运行原生窗口测试。后者在隔离配置中验证实际本机朗读、历史窗口显示、完整原文与原图预览、加密保存及图片导入导出，不覆盖系统剪贴板或正式用户数据。云端协议模拟测试不代表账户权限或云端音质验收。
