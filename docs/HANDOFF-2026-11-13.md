# 轻读工程交接

备份日期为 2026-11-13。本文件描述当前代码，优先于旧版交接文档与历史设计稿。

## 包内容

源码交接 ZIP 包含 src、tests、必要工具、使用说明、本交接文档和文件 SHA-256 清单。不包含发布运行库、bin/obj、旧源码快照、node_modules、个人正文、截图历史或密钥。不是个人数据迁移备份。

## 构建运行

Windows 10/11 x64，开发需要 .NET 9 SDK。首次恢复 NuGet 包需要联网。主项目为 src/LightReader.csproj，WPF + WinForms NotifyIcon，依赖 Markdig 0.41.3、NAudio、System.Speech、ProtectedData。

```powershell
dotnet build src/LightReader.csproj
dotnet run --project src/LightReader.csproj
./tools/Publish.ps1
```

发布始终覆盖 release/LightReader-win-x64。启动轻读.cmd 指向该目录，不是源码启动入口。Publish.ps1 按用户授权默认强制停止该目录中的运行进程，会中断朗读且可能丢失尚未保存编辑。成功后调用 Clean-OldBuilds.ps1 清理旧发布和编译输出，不另建功能版本目录。

Edge 为可选在线引擎，需要 Python 3.10+ 和 edge-tts 7.3.1+，运行 tools/Install-EdgeTts.ps1。Windows 本机语音无需 Python 或密钥。火山/豆包服务需要用户自行配置权限及密钥，可能计费。

## 当前功能与实现入口

- NativeReaderWindow.xaml/.cs 为主界面与播放协调。历史、设置嵌入主窗切换；正文工具常驻，悬浮与图钉并列。从光标读在播放器一行。Markdown 粘贴自动预览，普通文本保持编辑态。
- MarkdownReading.cs 使用 Markdig 解析并生成 WPF FlowDocument，保留 Run 到源文 UTF-16 位置映射。支持常用标题、列表、引用、强调、代码、链接标签；不自动加载外部图片，不运行 HTML。高级表格等扩展的完整排版仍待完善。
- SpeechText.cs 过滤整块 Markdown 代码、网址、路径、表情与装饰符号，以等长空格保持进度映射。行内代码术语保留，如 CosHalfAngleSq；不应再次全部过滤反引号内容。
- SentenceFocus.cs 和 ReportPosition 实现当前整句清晰、其他句子 35% 透明度，并保留正在朗读字词的蓝色背景。暂停保留，停止恢复。
- VoicePicker.cs 与 GlassTheme.xaml 提供虚拟化分类树，不能恢复为大量 ComboBoxItem 的平铺列表。Edge 按语言、地区、性别分组。
- GlassWindow.cs 用 WM_GETMINMAXINFO 限制最大化在当前显示器工作区内，不覆盖任务栏。Topmost 主窗图钉与 compact 状态分别维护。
- EdgeTtsClient.cs 和 Backends/edge_tts_bridge.py 实现 Python IPC、单段生成、边界映射；最多预取下一段。发送正文前压缩过滤后的空白并映射回原位置。等待秒数显示在播放按钮。
- Playback.cs 使用 NAudio，支持暂停、恢复、取消；缓冲连续五秒未消耗时报告设备异常。ReaderDiagnostics.cs 输出阶段信息，不写正文或密钥。
- NativeHistoryWindow/SettingsWindow 仍保留 Window 类型兼容实现，但 Page 内容挂到主窗，不 Show/ShowDialog。新增逻辑需区分嵌入场景，不直接依赖 DialogResult 或 Close 导航。

## 数据与安全

正式数据位于 %LOCALAPPDATA%/LightReader，使用当前 Windows 用户 DPAPI 加密。native-reader-v2.dat 保存阅读状态，history-images 保存原图；密钥与 Python 环境也在用户目录。不要打包该目录。数据导出是明文，须由用户主动执行。诊断日志为 playback-diagnostics.log，最大约 1 MB 后清空重写。

## 验证

```powershell
dotnet run --project tests -- --check-speech-filter
dotnet run --project tests -- --check-markdown
dotnet run --project tests -- --check-categories-tray
dotnet run --project tests -- --check-glass-ui
```

最近主窗回归通过，覆盖主窗历史与设置嵌入、Markdown 粘贴、清空、字体工具、句子透明度、词高亮移动、窄窗布局、最大化工作区、悬浮与置顶。旧测试部分可能仍按独立历史窗口编写，应按当前嵌入行为更新，不应因此改回弹窗。

显式联网验证为 --check-edge-completion、--check-edge-ui、--check-edge-live。completion 用云扬 1.5 倍、测试正文静音播放并检查跨段完成。不要未经用户授权用个人正文或火山付费服务做测试。用户曾报告段尾等待，短样例未稳定复现；已加等待提示、设备超时和阶段日志，不能宣称全部网络卡顿已彻底解决。

## 维护约束

沿用固定发布目录、清理脚本和既有数据兼容；不删除用户密钥/正文/截图，不擅自调用付费服务。现有界面构造部分仍复用原窗口内容并动态移动控件，后续可逐步提取 UserControl，但需回归历史载入、设置保存、主题刷新、异步取消与重复导航的生命周期。
